# FocusStride — Project Specification Document

## 1. Project Overview
* **Project Name:** FocusStride
* **Description:** FocusStride is a micro-habit and focus task manager designed for students and self-driven learners who struggle with procrastination and overwhelming project workloads.
* **Core Objective:** Break down daunting projects into structured, short-duration focus blocks (such as 10-minute focus sprints) and log daily micro-improvements through interactive timers and task prioritization.

## 2. Target Audience & User Stories
* **Audience:** Students, programmers, and independent learners managing heavy workloads.
* **User Story 1:** As a user, I want to break large projects into smaller tasks so that I don't feel overwhelmed.
* **User Story 2:** As a user, I want to run a 10-minute focus timer so that I can maintain momentum without burning out.
* **User Story 3:** As a user, I want to log my daily completed micro-habits to track consistency over time.

## 3. Technology Stack
* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
* **Backend / Database:** Node.js, MongoDB Atlas
* **Deployment:** Vercel

## 4. Key Features & Functionality
* **Task Breakdown Workflow:** Add, edit, and categorize micro-tasks into status boards.
* **Focus Sprint Timer:** Interactive countdown timer tailored for short sprint sessions.
* **Progress Dashboard:** Visual summary tracking daily completed habits and streaks.
