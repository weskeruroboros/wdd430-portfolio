# FocusStride — Micro-Habit & Focus Task Manager

FocusStride is a web application designed for students and self-driven learners who struggle with procrastination and overwhelming project workloads. The application allows users to break down daunting projects into structured, short-duration focus blocks (such as 10-minute focus sprints) and log daily micro-improvements through interactive timers and task prioritization.

## Tech Stack & Architecture
- **Framework:** [Next.js 16](https://nextjs.org) (App Router)
- **Language:** TypeScript
- **Styling & Design:** Tailwind CSS with mobile-first responsive grid layouts
- **Database:** MongoDB (via Mongoose / MongoDB Atlas)
- **Typography:** Google Fonts (`Inter` for UI clarity and `JetBrains Mono` for live timers)
